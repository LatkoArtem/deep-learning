# Лабораторна робота 3

Обчислювальний експеримент із ResNet-18 на Intel Image Classification: scratch, frozen та unfreeze за однакового бюджету у 304 кроки.

## Прогноз досліду з BatchNorm до запуску

У режимі frozen зі звичайним `model.train()` параметри замороженого кістяка не зміняться, але його `running_mean`, `running_var` і `num_batches_tracked` зміняться. Параметри `fc` зміняться. Спад train-loss сам по собі не дає змоги перевірити правильність заморожування.

Повні результати перевірок, семи запусків і окремої тестової оцінки будуть внесені після виконання експерименту.
